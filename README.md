# 🎲 自訂 Spot It! (哆寶) 圖卡生成器

這是一個基於 **React** 與 **Tailwind CSS** 開發的高效能網頁端教學工具。旨在幫助教師、家長與教育工作者快速製作客製化的「Spot It! (哆寶)」桌遊圖卡。透過精確的數學演算法，本工具能確保產出的任意兩張卡片之間，有且僅有一個相同的符號。

---

## ✨ 核心特色

*   **內容二選一模式**：支援純「圖片模式」與純「文字模式」，介面隨模式自動切換，專注不干擾。
*   **批次圖片處理**：支援一次選取多張去背 PNG 圖片，大幅省去重複上傳的時間。
*   **智慧文字排版**：
    *   **括號換行邏輯**：輸入 `單字 (補充)` 時，括號內容將在圖卡中自動強制換行呈現，適合雙語教學。
    *   **鎖定同行文字**：括號外的文字不論是否包含空格，皆會保持在同一行（Non-breaking space），確保排版工整。
*   **專業視覺微調**：
    *   **獨立縮放控制**：圖片與文字擁有各自的縮放拉桿，可分開調整視覺比例。
    *   **聚集度調校**：可手動調整符號向圓心靠攏或向邊緣擴散的程度。
*   **多樣化列印版面**：
    *   **A4 圓形 2 入**：經典圓形裁切排版，附帶淡淡的裁切虛線。
    *   **A5 矩形滿版**：將 A4 對半平分，適合製作大尺寸字卡，列印後直接對半剪開即可。
*   **所見即所得 (WYSIWYG)**：主畫面右側「即時排版預覽」與最終產出的 PDF 比例完全一致。

## 📐 數學原理

本工具的核心演算法基於幾何學中的**「有限投影平面」（Finite Projective Plane）**。
根據原理，階數為 $n$ 的平面具備以下特性：
1. 每張卡片上有 $n + 1$ 個符號。
2. 總共可產生 $n^2 + n + 1$ 張卡片。
3. 符號庫總數同樣為 $n^2 + n + 1$ 個。

本工具支援以下模式：
*   **入門版** ($n=2$)：每張 3 圖，共 **7** 張卡。
*   **迷你版** ($n=3$)：每張 4 圖，共 **13** 張卡。
*   **進階版** ($n=5$)：每張 6 圖，共 **31** 張卡。
*   **標準版** ($n=7$)：每張 8 圖，共 **57** 張卡。

## 🚀 使用教學

1.  **選擇模式**：於控制面板頂部切換「圖片」或「文字」模式，並選擇「列印版面尺寸」。
2.  **輸入內容**：
    *   **圖片模式**：點擊上傳圖示，批次選取準備好的去背 PNG 檔案。
    *   **文字模式**：在文字框逐行輸入內容。若需換行，請使用 `Word (Translation)` 格式。
3.  **微調排版**：透過拉桿調整「縮放倍率」與「中心聚集度」，直到預覽區排版滿意。
4.  **全螢幕預覽**：點擊「新視窗預覽與列印」，在新視窗做最後檢查。
5.  **輸出 PDF**：
    *   在列印選單中，目標選擇 **「另存為 PDF」**。
    *   **關鍵設定**：
        *   邊距：**無**（或設為 0）。
        *   背景圖形：**務必勾選**。
